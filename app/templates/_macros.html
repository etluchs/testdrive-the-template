{# appkit UI macro library — WCAG 2.1 AA by construction. Import in a template with: {% from "_macros.html" import field, select, button, table, alert, nav %} These macros are the ONLY sanctioned way to emit form and data markup in a golden-path app. Hand-writing , , etc. is how labels, header scopes, and focus states quietly go missing — so don't (see AGENTS.md).
